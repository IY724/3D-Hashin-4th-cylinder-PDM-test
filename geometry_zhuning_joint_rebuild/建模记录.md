# zhuning_joint_rebuild 建模记录（2026-09-26 建模，2026-09-27 铺层与基准定型）

交付物：`zhuning_joint_rebuilt.cae`（模型 `Zhuning_Joint_Rebuilt`）与 `WCM_Job.inp`。本项目当前以本目录为唯一计算基准。

## 1. 尺寸来源（朱宁论文 paper-fit v3）

- 依据：朱宁硕士论文（`references/REF3_朱宁-2023_浙江大学硕士论文_模型铺层与材料参数来源.pdf`）图2.2（第33页）像素拟合 + 图上标注尺寸。
- 整瓶：外径 280、筒身长 1282、总长 1520、直筒段内衬厚 5、封头椭圆比 2.0、瓶颈外径 72、通孔直径 32、扇区角 10°。
- 接头拟合值（整数候选，非论文原始标注，图像分辨率极限 5 mm）：内肩外圆角 R30、内肩内圆角 R28（两圆角间直段 27）、内环 R50、肩部轴向偏移 30、环端轴向偏移 -22、boss 分界半径 90、boss 界面环半径 43 / 圆角 R35 / 中心偏移 2、瓶颈圆角 R12、孔口圆角 R6。
- 注意：不声称 78 L 容积或规范合格；密封圈与螺纹未建。

## 2. 模型结构

- 源 Part（草图旋转 10° 扇区实体，BaseSolidRevolve）：
  - `PA6_Liner`：内衬，1 cell；
  - `Al6061_Bosses`：两端铝阀座，2 个独立 cell。
- 装配布尔合并：`InstanceFromBooleanMerge(name='Vessel_Base', keepIntersections=ON, originalInstances=SUPPRESS)`，生成单 Part `Vessel_Base`（3 cells：1 PA6 + 2 Al），原实例在装配中被抑制；不建 Tie、不建接触。
- 合并体上显式重指派截面（覆盖合并自动映射）：`Section_PA6 → 集合 MAT_PA6`（1 cell）、`Section_al-6061 → 集合 MAT_AL6061`（2 cells）；重开后同一截面出现两条指派（源映射 + 显式覆盖），单元数一致，属预期。
- `Section_t-700`：材料卡已建但未指派，作复材单层备用。

## 4. 集合与表面（Vessel_Base 上）

- 面：`SECTOR_0`(3)、`SECTOR_MINUS_10`(3)、`WCM_OUTER`(9)、`INNER_CAVITY`(21)、`END_FACES`(2)、`MATERIAL_INTERFACES`(8 个 PA6/Al 共享界面面)；除 MATERIAL_INTERFACES 外均建了同名 Surface。
- 边：`WCM_MERIDIAN_0`(9 条外表面子午线)。
- 轴：基准轴 `WCM_REVOLUTION_AXIS_Y`（全局 Y）。

## 5. 构建校验结果（2026-09-26 重开 CAE 校验 PASSED）

- 体积：内衬 193397.07 mm³、双阀座合计 60577.93 mm³、合并体 253974.99 mm³；与独立旋转面积分参考值偏差 <1e-4，合并体积损失 ~5.5e-10 mm³（无穿模）。

## 7. 建模方式备忘

原始做法为参数化脚本（`prepare_preview.py` 生成截面 JSON → `build_single_part_abaqus.py` 草图旋转 + 布尔合并，`verify_cae.py` 重开校验），脚本与参数/校验 JSON 已于 2026-09-26 清理放入回收站（parameters.json、scripts/、results/），需要复现时从回收站取回即可。GUI 手工重建要点：在 (r, y) 平面按上表尺寸画 10° 扇区封闭轮廓 → BaseSolidRevolve 10° → 两 Part 装配布尔合并（保留交界面、抑制原实例）→ 合并体上按材料集合指派均质截面。
