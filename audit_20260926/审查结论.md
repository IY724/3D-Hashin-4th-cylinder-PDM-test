# 气瓶渐进损伤代码审查（2026-09-26）

## 结论

对当前 `wcm_hashin_umat` 的评价是：**不同缠绕角度进入单层损伤计算的核心实现成立；在 WCM 等应变、±θ 双族均匀化假设下，已经具备螺旋层渐进损伤能力。但实际气瓶封头纤维方向和整瓶损伤预测尚未完成验证，不能判为全部需求验收通过。**

本次没有修改 Qoder 的源代码、配置和既有验证结果，没有提交整瓶求解。新增审查脚本、编译产物及证据全部位于 `audit_20260926`。

后续澄清：用户确认整瓶铺层及角度相关材料由WCM建立。本次进一步核读本机WCM手册，确认其会生成封头角度变化、材料分箱和AddRot；此前“尚未独立核验”不意味着WCM未考虑或错误处理封头角度。后续按同目录《WCM封头角度与UMAT接入验证计划.md》核对其与UMAT的对应，保留现有WCM建模方式。

## 为什么新版确实考虑了螺旋角

旧输入中的 Bin 工程常数是 WCM 角度均匀化常数，旧 UMAT 直接把该坐标系中的应力分量代入单层 Hashin 强度判据。弹性随角度变化，不等于纤维/基体失效方向也正确。

新版的链路是：

1. Abaqus 依据圆柱 `Orientation` 和逐单元 `AddRot` 提供局部坐标中的应变。UMAT 不重复做全局圆柱变换。
2. 转换器从各材料前的 `Beta` 注释取得缠绕角，并以原始 `t-700` 单层常数构造材料卡，避免再次旋转已经均匀化的刚度。
3. `WCM_EVAL` 将局部应变分别旋转到 +θ、−θ 纤维坐标，对两个方向分别调用 `WCM_PLY` 和 Hashin 判据。
4. 两个方向各存 40 个状态变量，各自演化损伤。应力通过 `Bᵀσ` 返回，刚度通过 `BᵀCB` 返回，然后按占比加权。
5. 返回完整 6×6 矩阵，允许两族损伤不相同时出现拉伸—剪切耦合。

代码依据：`wcm_core.for:160`（工程剪应变旋转），`:295–330`（双族独立计算及合成），`:251`（单层 Hashin）；`convert_wcm_inp.py:122–152`（Beta、单层常数和材料卡）。

**这是一层中 ±θ 两族共享宏观应变的均匀化模型，不是把每个正、反向物理单层分别离散。** 它可以记录两族不同损伤，但不自动包含显式层间应力跳变、脱层或任意铺层比例；当前配置统一采用 0.5/0.5。

## 实际输入的角度映射

本次逐单元审计了 `generated/Job_wcm_B.inp` 的 Tank-1。复合层共 52,344 个单元（52,338 个 C3D8、6 个 C3D6），材料截面没有漏赋、重复赋值；AddRot 没有缺项。材料角度共 138 种，范围 15°–90°。

筒身中段按单元形心位于各层轴向中央 10% 范围识别，不依赖名称可能有歧义的 `Center` 集。

| 02 | 90° | 90° |
| 03 | ±20° | 20°–90° |
| 04 | 90° | 90° |
| 05 | ±25° | 25°–90° |
| 06 | 90° | 90° |

| 08 | 90° | 90° |

这证明实际输入并非所有螺旋层都使用一个角度。封头侧的 Beta 分区和 AddRot 变化被保留，UMAT 通过不同材料卡使用这些角度。**UMAT 自身不依据坐标计算缠绕轨迹，也不在一个 Bin 内连续改变 θ；空间变化由上游 WCM 的分区、材料和取向映射提供。**

因此，还不能仅凭映射齐全就断言每个封头单元的方向与实际缠绕轨迹一致。本次未独立验证 WCM 原始轨迹、网格面法向与 Abaqus 实际积分点材料基底的对应关系。

## 本次实际重测

- 重新编译当前 Fortran 核心，重跑原有 13 项测试：全部通过。包含原代码历史回归、旋转功共轭、多个角度/占比、损伤独立性、切线、参数检查和全部 138 种材料转换。
- 另补 14 个离轴历史核对：A/B 各测试 15°、20°、25°、30°、35°、40°、60°。组合应变经历加载、卸载、再加载；分别将 ±θ 应变送入旧单层 Fortran，旋回应力后加权，与新核心逐增量比较。
- 两族历史与合成应力均通过，最大应力相对误差约 `9.92e-16`。例如 B 版 30°案例最终 +/− 族纤维拉伸损伤分别约 0.537/0.555，基体拉伸损伤约 0.764/0.848，说明不是两族强制共用一个损伤值。
- WCM 未损伤等效刚度与旧输入的最大相对差约 `6.81e-6`。

新增离轴核对属于**本构实现验证**，沿用原单层损伤规律，不能证明该规律本身或完整气瓶爆破预测具有物理准确性。所用特征长度为独立材料点测试的 0.01 mm，并非实际气瓶网格的长度。本次未重新运行 Abaqus 单元作业；既有 Abaqus 结果是通过日志和哈希复核的历史证据。

## 尚需补齐的验收项

### 1. 高优先级：实际封头材料方向还缺独立核验

转换器只要求目标实体截面带 `orientation`，没有验证该方向确实是子午/环向/厚度基底。当前旧输入使用圆柱坐标加 AddRot，符合预期结构；但任意其他 WCM 导出若已把 1 轴转到纤维方向，再使用本 UMAT 的 θ 会发生重复旋转。

建议在筒身、两侧过渡区、两侧封头和极孔附近，导出实际单元/积分点的 W1/W2/W3 与重建的 f±=cosθ·W1±sinθ·W2；逐层核对纤维切于铺层面、W3 沿厚度、两侧符号与角度定义一致。输出实际网格方向图与数值误差，不能仅画示意箭头。

### 2. 高优先级：整瓶 Data Check 有 2,287 条警告

既有 A/B 完整气瓶 Data Check 均完成，但 `.dat` 末尾报告 2,287 条警告，其中有节点反复作为 Tie 从属节点、自由度消除、过约束、部分节点未绑定及法向问题。它们不直接否定角度旋转公式，却会影响整瓶载荷传递与失效位置。应分类检查并修复或论证，不能把 `passed=true` 解读成整瓶模型没有问题。

证据：`wcm_hashin_umat/runs/abaqus_datacheck_B_20260925_231449_639164/verify.dat`，未绑定警告自第 4454 行可见，末尾是警告总数。

### 3. 中优先级：补 Abaqus 内的非零螺旋角损伤验证

`abaqus_verify.py:50` 的损伤套件只测试 0°和90°，占比为单族1.0；`:226–233` 主要检查预期起始标志和 B 版损伤大于零，不能覆盖完整双族损伤曲线。已有多角度弹性与刚体转动测试不能替代这一项。

本次新增核心离轴核对缩小了缺口，但还需 Abaqus 中的 ±15°/±30°/±45°组合载荷，比较两族 FI、损伤历史、应力—应变和耦合项，至少包含两族非同步损伤及卸载再加载。

### 4. 后续物理验收：软化与网格/步长敏感性

B 版默认保留旧损伤在下一增量生效的时序、首次触发增量端点的起始量、标量 CELENT 及纤维0.95/基体0.85损伤上限。这些是有意保留的建模选择，本轮角度修复不会自动消除其增量敏感性、方向相关网格敏感性和残余承载。

在角度链路验收之后，再用实际网格检查 delta_f>delta_0、载荷增量/黏性/网格敏感性，并比较论文或试验的首损伤压力、模式、位置和最终响应。无需为了角度修复先重写全部单层损伤公式。
