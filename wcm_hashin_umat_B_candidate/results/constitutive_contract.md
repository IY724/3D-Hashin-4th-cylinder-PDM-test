# B版能量渐进损伤：本构账本（constitutive contract）

日期：2026-09-27。范围：候选 `wcm_hashin_umat_B_candidate/src/wcm_core.for`（阶段1冻结版）与 `umat_entry.for.in`。单位：MPa、mm、N，G 为 N/mm，黏性为分析步时间单位。
标记含义：【官方】Abaqus文档定义；【论文】文献可溯（见 reference_matrix.csv）；【旧实现】沿用旧 hashin.for/WCM 代码，未做文献再证明；【待证】本轮取证后仍未证实。

## 1. 符号与作用层级

调用链：`WCM_UPDATE(MODE,P,OLD,E0,DE,DT,LC,IADV)` → `WCM_EVAL`（逐族旋转）→ `WCM_PLY`（族内：试验应力→判据→损伤）→ `WCM_DAMAGE_B`。
状态 84 维内部布局，每族 40 维：1:4 非黏性损伤 d，5:8 kappa，9:12 起始标志，13:16 delta0，17:20 sigma0，21:24 黏性损伤 DV，25:28 FI，29:34 应力，35:40 应变。INP 侧 B 版 62 SDV（SDV1–4 跨族最大 FI，5/6 非黏性组合损伤，7/8 黏性组合，9/10 本帧实际采用值），两族各 24 维 + 4 维标记。生产 UPDATE=0。

## 2. 弹性刚度 C0

- `WCM_ELASTIC`：由 9 个工程常数显式构造三维正交各向异性刚度（E11,E22,E33,ν12,ν13,ν23,G12,G13,G23）。【官方】标准公式；候选与独立柔度求逆参考最大误差 6.808e-6（rebuild 135 Bin 逐 Bin，见 validation/test_cases.json）。
- 生产参数 P1–9 = [141000, 11400, 11400, 0.28, 0.28, 0.28, 7100, 7100, 7100]。
- 作用层级：EFF = C0·EL 用于判据与等效应力；试验应力 S = C(d)·EL。

## 3. 局部旋转（WCM_ROTATE）

- W 轴→±θ 纤维轴的 6×B 工程应变旋转，EL=B·E，应力回转 S+=w·Bᵀ·SL；两族权重 w=0.5/0.5，w=0 的族跳过。【旧实现】WCM 双族代码；旋转正确性有独立张量参考（run_tests 的 rotation/power 测试）。

## 4. Hashin 起始判据（WCM_HASHIN，作用对象 EFF）

EFF = C0·EL（无损伤等效应力）。P10–16 = XT,XC,YT,YC,S12,S13,S23 = [2080, 1250, 60, 290, 110, 110, 110]。【论文】朱宁-2023 式(1.4)–(1.7) 对齐（tau13 分母用 S12=P14，不回退 P15）；基础为 Hashin 1980 三维扩展。【旧实现】符号分支结构沿旧代码：

- FT（S1≥0）：FI1 = (S1/XT)² + (S4/S12)² + (S5/S12)²
- FC（S1<0）：FI2 = (−S1/XC)²
- MT（Q=S2+S3≥0）：FI3 = (Q/YT)² + (S6²−S2·S3)/S23² + (S4/S12)² + (S5/S12)²
- MC（Q<0）：FI4 = ((YC/(2·S23))²−1)·Q/YC + Q²/(2·S23)² + (S6²−S2·S3)/S23² + (S4/S12)² + (S5/S12)²

注意：FI 按符号分支二选一非零，另一支恒 0；"未起始"必须结合分支有效性判断（候选修正已实现）。

## 5. 等效应力与等效位移（WCM_EQ，作用对象 EL 与 EFF）

【论文】等效位移/等效应力定义来源 REF2 Zhang-2024；【旧实现】当前具体组合式沿旧代码：

- Δ1 = LC·√(max(E1,0)² + E4² + E5²)；Σ1 = LC·(max(S1,0)·max(E1,0) + S4·E4 + S5·E5)/Δ1
- Δ2 = LC·max(−E1,0)；Σ2 = LC·max(−S1,0)·max(−E1,0)/Δ2
- Δ3 = LC·√(max(E2,0)² + max(E3,0)² + SH)，SH = E4²+E5²+E6²；Σ3 = LC·(max(S2,0)·max(E2,0) + max(S3,0)·max(E3,0) + S4·E4 + S5·E5 + S6·E6)/Δ3
- Δ4 = LC·√(max(−E2,0)² + max(−E3,0)² + SH)；Σ4 = LC·(max(−S2,0)·max(−E2,0) + max(−S3,0)·max(−E3,0) + SH)/Δ4

待证点（规划5.3特别检查）：FC 由 EFF11<0 触发，但 Δ2 只取 EL11<0；三维泊松耦合下"应力压、应变拉"时 Σ2=Δ2=0，起始量无法定义 → 1022。现场根因未证实（见 validation/forensics_1022.json）。

## 6. 起始量 delta0 / sigma0

- 冻结版（缺陷）：首次 FI≥1 的**增量端点**值 Δ(I)、Σ(I)。已证步长依赖：同终点 γ=0.02、Lc=0.3，1 步给 δ0=6.0e-3 mm/σ0=142 MPa，20 步给 δ0=4.8e-3 mm/σ0=113.6 MPa（validation/reproduction.json）。
- 候选修正（阶段2）：沿增量应变路径 EL(s)=B·(E0+s·(E1−E0)) 定位最早有效 s0（FI≥1 且 Δ>0、Σ>0），δ0/σ0 用原 WCM_EQ 在 s0 处计算；已起始模式不重写。端点越限而状态未起始 → 新错误 41–44（缺少可定位历史）。

## 7. 损伤演化（B，线性软化）

【论文】参数来源 Wu-2024 Table 1（G 值）；【旧实现】演化公式沿旧 hashin.for：

- 起始后：κ = max(κ_old, δ0, ΔI(端点))（候选修正加入 δ0 下限）；δf = 2·G_i/σ0
- d_i = δf·(κ−δ0)/(κ·(δf−δ0))，clamp [0,1]，且不回退（不愈合）
- 若 δf ≤ δ0：严格报错 31–34（31/33 已在整瓶取证出现）；这是**固有长度/能量不相容**信号，不是数值缺陷。
- G = [GFT,GFC,GMT,GMC] = [133, 10, 0.5, 1.6] N/mm。G 的含义 = 全 OAC 面积（官方平面应力定义，SIMACAEMATRefMap damageevolfibercomposite）；三维实体下该含义【待证】——阶段3B的解析负对照显示剪切模式实际耗能为 0.9·G（见 §10）。

## 8. 损伤组合与刚度退化（B，WCM_STIFF）

【旧实现】沿旧刚度形式（非 REF2 完整移植）：

- DF = 1−(1−dFT)(1−dFC)，DM = 1−(1−dMT)(1−dMC)；cap：DF≤CAPF=1，DM≤CAPM=1
- RF = max(1−DF, 1e-6)，RM = max(1−DM, 1e-6)，RS = clamp((1−0.9·dMTv)·(1−0.5·dMCv), 1e-6, 1)
- C11 = RF·C0(1,1)；C22/C33 及法向非对角 = RF·RM·C0(i,j)（注意 C22 含 RF）；C44=C55=C66 = RS·C0(i,i)
- dMtV/dMcV 为**黏性**损伤（§9），即刚度由 DV 驱动。
- 黏性记号：dMTv 按 (1−0.9d) 退化、dMCv 按 (1−0.5d) 退化，两因子相乘。仅 dMTv=1 时剪切刚度仍剩 10%。

## 9. 黏性正则化

【旧实现】Darcy 型递推：DV_i = (η·DV_old + DT·d_i)/(η+DT)；η_f=P24=1e-4（模式1/2），η_m=P25=5e-3（模式3/4）。η=0 或 DT=0 时 DV=d。作用层级：DV 进刚度；非黏性 d 进状态与 SDV5/6。

## 10. 应力与能量输出

- 应力：S = C(DV_used)·E1。UPDATE=0（生产）：DV_used 为旧增量 DV（滞后一步）；UPDATE=1（诊断）：本增量新 DV 并用同 OLD 差分切线。
- 两族回转叠加：S = Σ_k w_k·B_kᵀ·S_k；切线 C 同理。跨族最大值仅进 SDV 展示，不参与任何力学量。【旧实现】
- SSE = 0.5·σ:(E0+DE)（有符号近似）；SPD += 0.5·(σ_old+σ_new):ΔE − (SSE−SSE_old)。【旧实现】两者均为有符号诊断输出，不能当各模式断裂能（规划8.1）。
- 能量账本（阶段3B核验口径）：ΔW=0.5(σ_n+σ_{n+1}):Δε（工程剪应变功配对）；Ψ=0.5·εᵀC(DV_used)ε；ΔD=ΔW−ΔΨ；双族按 0.5 权重分别记账。裂带能 = Lc×体积耗散密度。

## 11. LC / CELENT

【官方】CELENT 为典型单元长度（SIMACAESUBRefMap 844–853 行），非所有单元精确体积立方根；UMAT 收到的即该值，候选不替换、不截断。整瓶复材 LC≈2.23–2.34 mm（Bin 102/112/129/150 取证值）。

## 12. 长度/能量相容域（该路径条件，非全瓶网格建议）

δf > δ0 ⟺ LC < 2·G_i·G_dir/Σ0²（模式相关；G_dir 为该模式主导方向模量）：
- 纯剪基体拉伸（23 或 12，S12=S23=110）：LC_crit = 2·7100·0.5/110² = 0.586777 mm
- γ12 纯剪同时激活 FT 与 MT（FI1=FI3=(S4/S12)²）；FT 在 Lc=2.23 mm 相容（δf_FT=2·133/110.05=2.417 mm），MT 不相容（δf_MT=0.00909 mm < δ0=0.03457 mm）→ 1033。
- 整瓶 9 个取证单元（Bin 102/112/129/150，Lc≈2.28–2.34 mm）全部属此类固有不相容。

## 13. 错误码（候选新增 41–44）

21–24 起始等效量非正；31–34 δf≤δ0；41–44 未起始状态在增量起点已越限（缺少可定位起始历史，不允许伪造早于当前增量的起始点）。族号 = 商（×1000），模式 = 余数。

## 14. 阶段4增补（2026-09-27）：FE噪声鲁棒性与切线语义

1. **噪声尺度**：FE舍入使各积分点的法向应变带 ±1e-19 量级互不相同的噪声（实 Scale 证据：fixture单行trace）。WCM_ONSET_B 以 EPSG=1e-10·max|EFF0,EFF| 为符号有效阈值；|Q|、|S1| 全程在带内时按 WCM_HASHIN 的约定（Q≥0、S1≥0 归张力支）由**张力模式拥有整条路径，压缩模式不起始**（确定性，跨积分点一致）。
2. **候选点分支过滤**：每个候选播种点须使 GC=G0+s·GD 落在本模式自己的分支内（张力 GC≥−EPSG；压缩 GC≤−EPSG）。边界共享剪切面归张力支所有——否则切线扰动会让 MC 在共享面上虚播种并触发 1034。
3. **切线 IONSET=0**：WCM_TANGENT_B 的差分子调用不执行起始定位、端点回退与 40+I 检查（IONSET 形参，主调用恒为 1）；已起始模式的演化与 δf 检查照旧。起始是状态史决策，不属于切线求导语义。此为对规划6.1"完整B映射"的有记录收窄。
4. **错误码语义细化**：40+I 仅在 E0 处分支**有意义地**处于本模式且 FI0≥1 时触发；噪声带内的"已越限"由搜索在 s=0 以正确起始量播种（s=0 在路径上，不属伪造历史）。压缩模式在噪声带内静默返回。
